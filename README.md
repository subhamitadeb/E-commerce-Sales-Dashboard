
# 🛒 E-Commerce Sales Dashboard — Power BI

## 📊 Project Overview

This project is an **E-Commerce Sales Dashboard built using Microsoft Power BI**. The dashboard provides an interactive view of sales performance, profit, quantity, customer contribution, product categories, payment modes, states, and monthly profit trends.

The main objective of this project is to transform raw e-commerce sales data into a **clear and interactive business intelligence dashboard** that can help identify sales trends and business performance.

---

## 🎯 Project Objectives

* Analyze overall e-commerce sales performance
* Track total sales, profit, quantity, and average order metrics
* Analyze sales performance across different states
* Identify the contribution of different product categories
* Analyze customer-wise sales
* Understand payment-mode preferences
* Identify profitable sub-categories
* Analyze monthly profit trends
* Create an interactive dashboard for business decision-making

## 📊 Dashboard Features

### 1. Sales by State

The dashboard compares sales performance across different states and helps identify the highest-performing locations.

### 2. Quantity by Category

The category analysis shows the contribution of:

* Clothing
* Electronics
* Furniture

Clothing represents the largest share of quantity in the current dashboard.

### 3. Profit by Month

The monthly profit chart helps identify:

* High-profit months
* Low-profit months
* Negative-profit periods
* Seasonal patterns

### 4. Sales by Customer

The customer analysis highlights the contribution of individual customers to overall sales.

### 5. Quantity by Payment Mode

The dashboard analyzes different payment methods:

* COD
* UPI
* Debit Card
* Credit Card
* EMI

This helps understand customer payment preferences.

### 6. Profit by Sub-Category

The sub-category analysis compares profitability across products such as:

* Printers
* Bookcases
* Saree
* Accessories
* Tables

## 🎛️ Interactive Features

The dashboard includes interactive controls that allow users to:

* Filter data by quarter
* Filter data using the dropdown slicer
* Explore different categories
* Compare monthly performance
* Analyze customers and products
* Interact with visual-level filters

---

## 💡 Key Business Insights

Based on the current dashboard:

* **Clothing** contributes the largest share of total quantity.
* **COD** is the most frequently used payment method.
* **Printers** appear to be the strongest sub-category by profit.
* Monthly profit varies significantly throughout the year.
* Some months show negative profit, indicating periods that may require further investigation.
* Sales performance differs considerably across states and customers.
